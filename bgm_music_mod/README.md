# BGM App MOD



版本：1.2.3。增加独立播放模式、收藏和收藏列表按钮，位于原有分类按钮下方。恢复原始歌曲名称与介绍，已收藏歌曲在列表曲名前显示 ★。切换分类时保留正在播放曲目的名称与介绍。收藏列表支持原生按钮点击进入及返回。



安装后重新启动游戏，进入 BGM 鉴赏即可加载。实际安装状态以管理器检测为准。



点击原有循环按钮，或按 **M**，依次切换：单曲循环 → 顺序循环 → 随机播放 → 顺序播放 → 单曲播放。当前模式显示在新增的播放模式按钮上，选择会自动保存。



| 功能 | 操作 |

| --- | --- |

| 上一首 / 下一首 | 原有按钮，或键盘 ← / → |

| 暂停 / 继续 | 原有暂停按钮，或空格 |

| 切换播放模式 | 新增模式按钮、原有循环按钮，或 M |

| 指定播放位置 | 拖动原有进度条，松开后提交；暂停时显示并保存目标，继续时从该位置播放 |



## 五种播放模式



模式作用于当前分类或收藏列表中已解锁的曲目，点击循环按钮或按 M 依次切换，选择自动保存。上一首／下一首仍可手动切歌。



| 模式 | 歌曲自然结束后的行为 |

| --- | --- |

| 单曲循环 | 从头重播当前整首歌曲，持续循环。 |

| 顺序循环 | 按列表顺序播放下一首；最后一首结束后回到第一首。 |

| 随机播放 | 从洗牌队列取下一首；本轮用完后重新洗牌，继续播放。 |

| 顺序播放 | 按列表顺序播放下一首；最后一首结束后停止，不回到开头。 |

| 单曲播放 | 当前歌曲播放一遍后停止，不自动切换下一首。 |



## 随机播放原理与种子



复用游戏的 `getNextRandomPlay()` 与 `shuffle()`：收集当前分类所有已解锁曲目，每次随机抽取其中一首、从候选列表删除，直到生成完整洗牌队列；播放时逐首取出，队列空了再生成下一轮。因此正常向前播放时，同一轮的队列曲目不会重复；手动选曲或回到上一首可能再次听到同一首。每轮生成时，如果队列第一首恰好等于当前歌曲，会把它移到队尾；只有一首可播放歌曲时仍会重复。



**没有写死固定种子，也不把种子存进存档。** 原游戏每次洗牌使用无参数的 `new Math.RandomGenerator()`，使用引擎默认种子机制。官方 TJS2 实现采用 Mersenne Twister 伪随机数生成器：优先使用宿主引擎提供的随机种子接口；未提供接口时使用当前时间初始化。这里不是每次启动都用同一个固定数字，也不是保证每次洗牌顺序一定不同；随机结果可能偶然相同。由于本游戏没有公开其内部种子接口实现，不能断言其具体熵源只来自时间或某个系统接口。



切换播放模式或歌曲分类会清空随机队列和历史，下次随机切歌重新生成队列；重新进入鉴赏时也重新建立队列。随机模式的“下一首”取队列下一项，“上一首”从游戏保存的最近播放历史中取出，最多保留 100 首；返回上一首不会把整个随机队列倒退。



实现依据：插件 `player.tjs`，游戏原有 `SoundGalleryMode` 的 `shuffle/getNextRandomPlay/randomStore/randomMove`。引擎种子机制参考 [官方 TJS2 RandomGenerator 源码](https://github.com/krkrz/krkrz/blob/master/tjs2/tjsRandomGenerator.cpp)。



## 安装文件和卸载



双击 `BGM_Mod_Manager.exe`，选择包含 `MaitetsuLastRun.exe` 的游戏目录，然后点击 **安装／更新** 或 **卸载 MOD**。放在游戏目录或其直接子文件夹时会自动选中游戏目录。操作前先关闭游戏，完成后重新启动。



状态检测以游戏目录的 `patch.xp3` 和 `bgm_music_mod/player.tjs` 为准：两者均通过已知版本的 SHA-256 校验才显示已安装；播放器缺失或损坏显示安装不完整；只有播放器、没有活动补丁时显示未安装／已停用。说明文件不影响运行状态。没有游戏 EXE 的备份目录不能被当作安装目录，返回管理器窗口时会重新检查状态。



EXE 内置全部必要 MOD 文件，无需另外解压或安装运行库。支持重复安装、卸载与旧版升级；通过 SHA-256 识别本版本及已知旧版文件。遇到其他 `patch.xp3` 或被改动的 MOD 文件时停止操作并显示原因。卸载仅移除识别出的补丁、播放器脚本与说明，保留用户额外文件、开发文件和存档；安装器本身可保留，随时重新安装。



- 游戏目录中的 `patch.xp3`：仅覆盖 BGM 鉴赏的界面配置。

- `bgm_music_mod/player.tjs`：音乐控制扩展源码。

- `bgm_music_mod/original_extra_music.func`：提取并解码的原界面配置备份。

- `bgm_mod_work/`：开发工具、独立测试和解码分析副本，不参与日常游戏运行。



也可手动停用：关闭游戏，将游戏目录的 `patch.xp3` 重命名为 `patch.xp3.disabled`，恢复时改回原名。原始 EXE、资源包和存档均未被本 MOD 修改。



发布包 `BGM_App_MOD.zip` 解压后运行其中的管理器安装／更新。

## 开发和自检



构建脚本：`bgm_mod_work/build_mod.py`。自检脚本：`bgm_mod_work/check.tjs`，通过独立官方引擎运行；不要用它替换游戏的 `startup.tjs`。



安装器源码：`bgm_mod_work/ModManager.cs`，构建脚本 `bgm_mod_work/build_installer.ps1` 使用 Windows 自带 .NET Framework 编译器；`BGM_Mod_Manager.exe --self-test <测试输出目录>` 可运行安装／卸载、其他补丁保护、修改文件保护和失败回滚检查。自检仅在测试目录内创建随机命名的模拟游戏子目录，保留该子目录供检查；提供已知旧版 `legacy-player.tjs` 时还会检查升级。



官方测试引擎：[krkrz/krkrz](https://github.com/krkrz/krkrz/releases/tag/1.4.0r2)。资源分析参考：[GARbro](https://github.com/morkt/GARbro/tree/master/ArcFormats/KiriKiri)、[TJS2 反编译器](https://github.com/crate-1556/tjs2-decompiler)。这些工具仅用于分析与验证，MOD 日常运行不依赖它们。
